Déposer ici les binaires téléchargés depuis splunk.com (ignorés par Git) :

- splunk-<version>-<build>-Linux-x86_64.tgz
- splunkforwarder-<version>-<build>-Linux-x86_64.tgz
- (optionnel) Splunk.License  — licence Enterprise / Developer

En mode `splunk_download_from: artifactory`, ils sont récupérés depuis Artifactory à la place.
